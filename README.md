# HR Analytics Dashboard — Employee Attrition & Workforce Insights

## Overview
This project presents an interactive Power BI dashboard built to analyze employee attrition and workforce trends within an organization. The dashboard was developed to help HR teams and business leaders identify patterns behind employee turnover, monitor workforce composition, and make data-driven retention decisions.

## Project Files
- **HR_Dashboard.pbix** — The Power BI project file containing the full interactive dashboard, data model, and DAX measures.
- **HR_Project_Power_BI.csv** — The underlying dataset used to build the dashboard, containing employee-level HR records.
- **Dashboard.png** — A static screenshot preview of the dashboard for quick reference.

## Key Metrics Displayed
The dashboard highlights several core KPIs at a glance:
- **Total Employees** — 1.47K
- **Attrition Count** — 237
- **Attrition Rate** — 16.12%
- **Average Monthly Income** — 6.50K
- **Average Years at Company** — 7

## Dashboard Features
The report is organized into multiple visual sections to support deep-dive analysis:

1. **Job Satisfaction Matrix** — A breakdown of employee counts by job role against satisfaction rating levels (1–4).
2. **Income vs Tenure by Department** — A scatter plot comparing average monthly income against years at the company, segmented by department (Human Resources, Research & Development, Sales).
3. **Attrition Count by Department** — A bar chart comparing attrition volume across departments.
4. **Attrition Count by Job Role** — A treemap visualizing attrition distribution across job roles such as Laboratory Technician, Research Scientist, Sales Executive, and Sales Representative.
5. **Attrition Count by Tenure Group** — An area chart showing how attrition trends change across employee tenure brackets (0–2 years, 3–5 years, 6–10 years, 11–15 years, 16+ years).
6. **Attrition Count by OverTime** — A donut chart comparing attrition rates between employees who work overtime and those who do not.

## Filters
Users can slice the data dynamically using the following filter panel options:
- Department
- Job Role
- Gender
- Business Travel
- OverTime

## Tools Used
- **Power BI Desktop** — for data modeling, DAX calculations, and dashboard design.
- **CSV dataset** — as the primary data source for employee records.

## Purpose
The dashboard was created to demonstrate how HR data can be transformed into actionable visual insights, enabling stakeholders to identify at-risk employee segments, understand the drivers of attrition, and support strategic workforce planning.

## How to Use
1. Download **HR_Dashboard.pbix** and open it in Power BI Desktop.
2. Use the filter panel on the left to explore attrition patterns by department, role, gender, travel frequency, or overtime status.
3. Hover over visuals for detailed tooltips and drill-down insights.
